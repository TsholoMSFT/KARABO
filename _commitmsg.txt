feat(metadata): auto-enrich customer financials from ticker

When a stock ticker is set in Session Metadata (manually, via demo
mode, or via the auto-suggest), call /api/company-financials and
back-fill annualRevenue, employeeCount, and industry/sector context
into manualFinancials when fields are empty. Surfaces an "AI inferred"
badge with the source list (Yahoo / SEC EDGAR / Alpha Vantage / etc.).
